# 1주차 프로토타입 작업 목록

목표: 도형과 색만으로 "한 판이 재밌는가"를 확인한다. 기획은 [concept.md](concept.md) 참고.
제외: 보스, 이벤트, 상점, 2번째 캐릭터, 메타 성장, 아트/사운드.

## 원칙
- 숫자(체력, 공격력 범위, 잠식 증감, 블록 출현 비율, 핸드 크기, n)는 코드에 박지 않고 한 곳(ScriptableObject)에서 바꾼다.
- 게임 규칙(격자, 블록, 전투 계산)은 화면 코드와 분리해 순수 C#으로 두면 테스트와 수정이 쉽다.

## 작업 순서

### 1일차: 격자
- [ ] 프로젝트 폴더 정리, .gitignore 확인
- [ ] 5x5 격자 데이터 (칸 종류: 몬스터 / 보상 / 보이드 / 비어 있음, 발동 여부)
- [ ] 격자를 색 사각형으로 표시, 판마다 칸 종류를 무작위 채움
- 완료 기준: 실행하면 매번 다른 5x5 격자가 보인다.

### 2일차: 블록
- [ ] 블록 10종 정의 (도미노 1, 3칸 2, 4칸 7), 회전 함수 (뒤집기 없음)
- [ ] 핸드 3개 무작위 제시, 클릭으로 선택, 회전 키(R/우클릭)
- [ ] 출현 비율을 설정 데이터로 분리
- 완료 기준: 블록을 고르고 돌려 볼 수 있다.

### 3일차: 배치와 발동
- [ ] 마우스 위치에 미리보기, 놓을 수 있는 칸인지 검사 (격자 안, 발동 안 된 칸)
- [ ] 놓으면 겹친 칸 발동, 칸이 잠김
- [ ] 사용한 블록만 리필, 최소 하나는 놓을 수 있게 보장
- 완료 기준: 블록을 놓으면 칸이 잠기고 새 블록이 채워진다.

### 4일차: 전투
- [ ] 몬스터 칸에 공격력 숫자 표시
- [ ] 내 공격력 범위(4~8)를 굴려 비교: 이기면 처치, 지면 차이만큼 체력 감소
- [ ] 몬스터 위에 승률 표시
- [ ] 체력 UI, 체력 0이면 패배
- 완료 기준: 몬스터 칸을 덮으면 결과가 나오고 체력이 줄어든다.

### 5일차: 보이드와 잠식
- [ ] 보이드 칸은 여러 번 발동 가능 (잠금 안 됨)
- [ ] 발동 시 잠식 증가, 잠식에 따라 보상/몬스터 확률 결정
- [ ] 몬스터 결과는 공격력이 잠식에 비례하는 몬스터를 등장시켜 전투
- [ ] 잠식 게이지와 현재 확률 표시
- 완료 기준: 보이드를 반복하면 몬스터가 늘고 강해진다.

### 6일차: 라운드 루프
- [ ] 라운드 종료: 놓을 자리가 없거나, n회(임시 3) 행동 후 수동으로 넘기기
- [ ] 라운드 종료 시 잠식 -2, 손 비우고 새 격자 생성
- [ ] 5라운드 완료 시 클리어, 체력 0이면 패배, 다시 시작
- 완료 기준: 처음부터 끝까지 한 번 완주할 수 있다.

### 7일차: 플레이테스트와 조정
- [ ] 혼자 5판 이상 플레이하고 메모
- [ ] 다른 사람 1~2명에게 해 보게 하고 반응 기록
- [ ] 설정값을 바꿔 가며 조정 (격자 크기 6x6, 핸드 2/3, 확률 곡선)
- 판정 질문: 위치를 고민하게 되는가 / 잠식을 보고 망설이게 되는가 / 한 번 더 하고 싶은가
