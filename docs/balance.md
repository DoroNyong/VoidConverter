# 밸런스 기록 (임시)

사람이 수백 판을 돌리기 어려워서, 자동 플레이어(봇)로 수천 런을 돌려 숫자를 잡았다.
골드를 쓸 곳(상점, 성장)과 보스가 없는 상태의 기준선이며, 다음 주에 성장 요소가 들어오면 다시 맞춘다.

## 측정 도구
- `Assets/Editor/BalanceSim.cs`. 플레이 모드에서 `BalanceSim.Compare(c => { 값 바꾸기 }, 런 수)`나
  `BalanceSim.Run(설정, 봇, 런 수, 시드)`로 호출한다. 수천 런이 몇 초 안에 끝난다.
- 봇 3종
  - Random: 아무 합법적인 배치. 바닥선(클리어하면 안 됨)을 재는 용도.
  - Passive: 기대 피해를 최소화하고 보상은 챙긴다. 일부러 싸우지 않는 플레이.
  - Greedy: 기대 골드와 회복에서 기대 피해와 잠식 증가를 뺀 값이 큰 배치. 비교적 잘하는 플레이.
- 봇은 사람보다 단순하다. 사람은 손에 든 블록을 아껴 쓰거나 수동 넘기기를 쓰는데 봇은 쓰지 않는다.

## 목표
| 봇 | 목표 클리어율 | 이유 |
|---|---|---|
| Random | 0~2% | 아무렇게나 해서는 못 깨야 한다 |
| Passive | 20~35% | 소극적으로만 해도 가끔은 깰 수 있지만 쉽지는 않다 |
| Greedy | 45~60% | 잘하면 절반 정도, 성장 요소 없이 기본 힘만으로 |
| 1라운드 사망 | 3% 미만 | 시작하자마자 죽으면 안 된다 |

## 격자 생성 규칙 (Assets/Scripts/Core/GridLayout.cs)
칸을 칸마다 무작위로 뽑으면 한 종류가 뭉치거나 한 판에 나오는 수가 들쭉날쭉해서, 개수를 먼저 정하고 위치를 배치한다.
- **보이드 칸은 정확히 5개.** 서로 대각선으로도 붙지 않는다(`voidMinSpacing` 2).
- **최소 개수:** 몬스터 10, 골드 2, 회복 1. 나머지 칸은 5:1:1 비율로 나눠 갖는다 (평균 몬스터 15, 골드 3, 회복 2, 보이드 5).
- **보상 칸(골드, 회복)끼리는 변을 맞대지 않는다**(`rewardMinSpacing` 2).
- **몬스터가 변으로 이어진 덩어리는 8칸을 넘지 않는다**(`monsterMaxCluster` 8). 이 상한은 밸런스에 거의 영향이 없고(상한 0~6에서 클리어율이 거의 같음) 생김새만 다듬는다.
- 규칙을 못 지키는 경우를 대비해 단계별로 풀도록 했지만, 4만 판에서 푼 경우는 한 번도 없었다 (판당 0.13ms).

## 현재 값과 결과 (4000런)
체력 30, 공격력 5~12, 몬스터 공격력 3~9, 라운드당 배치 6회, 5라운드, 잠식 감소 2, 위 격자 규칙.

| 봇 | 클리어 | 평균 도달 라운드 | 클리어 시 남은 체력 | 평균 골드 |
|---|---|---|---|---|
| Random | 0% | 2.1 | - | 39 |
| Passive | 34% | 4.2 | 12 | 121 |
| Greedy | 53% | 4.5 | 15 | 156 |

사망은 2~5라운드에 고르게 퍼지고 1라운드 사망은 거의 없다. 싸우는 쪽(Greedy)이 골드를 약 29% 더 번다.

## 격자 규칙을 바꿨을 때의 변화 (참고)
격자 규칙을 새로 넣으면 이전보다 훨씬 쉬워졌다 (체력 30, 공격력 5~12, 몬스터 최소 10, 회복 최소 2 기준: Passive 56%, Greedy 76%).
보이드와 보상 칸이 흩어져서 한 블록이 여러 보이드를 한꺼번에 밟는 일이 줄고, 보이드 수가 5.6개에서 5개로 줄었기 때문이다.
그래서 회복 칸 최소를 1로 낮춰 목표 범위로 되돌렸다.

## 민감도 (새 격자 규칙, 공격력 5~12, 몬스터 최소 10 기준에서 하나만 바꿨을 때, 1500런, 클리어율 Passive/Greedy)
| 바꾼 값 | Passive / Greedy |
|---|---|
| 회복 최소 2 (이전 값) | 55 / 77 |
| **회복 최소 1 (현재)** | **34 / 54** |
| 몬스터 최소 12, 회복 최소 1 | 21 / 38 |
| 몬스터 최소 12, 회복 최소 2 | 44 / 63 |
| 몬스터 최소 14, 회복 최소 2 | 31 / 50 |
| 몬스터 최소 12, 회복 최소 1, 골드 최소 3 | 31 / 50 |
| 배치 횟수 7 | 7 / 18 |
| 몬스터 공격력 3~10 | 43 / 65 |
| 몬스터 공격력 4~9 | 36 / 52 |
| 공격력 5~11 | 52 / 70 |
| 공격력 5~10 | 43 / 63 |
| 잠식 감소 1 | 43 / 61 |

(이전 격자 규칙에서 측정한 표는 바뀐 규칙에서는 맞지 않아 지웠다. 큰 경향은 같다: 배치 횟수가 가장 민감하고, 회복 칸, 몬스터 칸과 공격력, 보이드 비율이 그다음이다.)

## 읽는 법
- **가장 민감한 것은 라운드당 배치 횟수다.** 한 번 더 놓으면 격자가 더 차서 어쩔 수 없는 전투가 늘어 클리어율이 크게 떨어진다. 게임의 템포이기도 해서 신중히 바꿔야 한다.
- 난이도를 조금만 조절하고 싶을 때는 **회복 칸 최소 개수, 몬스터 최소 개수, 잠식 감소**가 비교적 부드럽다.
- 체력 소모는 "회복 칸 수 x 회복량"이 지킨다. 체력을 너무 쉽게 유지하지 못하게 하려면 이 둘을 낮춘다.

## 아직 반영되지 않은 것
- 몬스터 공격력이 라운드가 가도 올라가지 않는다. 난이도 상승이 없다.
- 골드 사용처(상점, 성장)와 보스가 없다. 성장이 들어오면 기준선이 쉬워지므로, 그때 몬스터 공격력 상승이나 보스를 더해 다시 맞춘다.
- 처치 골드 배율(1)은 클리어율에 영향이 없다. 상점 가격을 정할 때 함께 정한다.
